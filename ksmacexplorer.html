การติดตั้งและการตั้งค่าที่สำคัญ

1. การเปิดแอปครั้งแรก (Gatekeeper)

เนื่องจากแอปไม่ได้แจกจ่ายผ่าน App Store ระบบ macOS อาจบล็อกและแจ้งเตือนเมื่อเปิดใช้งานครั้งแรก คุณสามารถแก้ไขได้ 3 วิธี:

  • วิธีที่ 1: คลิกขวา (Right-click) ที่ไอคอนแอป KSMacExplorer แล้วเลือก Open (เปิด) จากนั้นกดยืนยัน
  • วิธีที่ 2: ไปที่ System Settings > Privacy & Security เลื่อนลงมาที่หัวข้อ Security แล้วคลิกปุ่ม Open Anyway (อนุญาตต่อไป) เพื่อให้แอปทำงานได้เสมอ
  • วิธีที่ 3: เปิดแอป Terminal ใน Mac แล้วคัดลอกคำสั่งด้านล่างนี้ไปรัน เพื่อปลดล็อคแอป:
xattr -cr /Applications/KSMacExplorer.app

2. การอนุญาตให้จัดการไฟล์ (Full Disk Access)

เพื่อให้ KSMacExplorer สามารถเข้าถึงและจัดการไฟล์ได้ครอบคลุมทุกโฟลเดอร์ในเครื่อง กรุณาตั้งค่าตามนี้:

  1. ไปที่ System Settings (การตั้งค่าระบบ) > Privacy & Security (ความเป็นส่วนตัวและความปลอดภัย)
  2. เลื่อนหาและคลิกที่เมนู Full Disk Access (การเข้าถึงดิสก์ทั้งหมด)
  3. เปิดสวิตช์ด้านหลังแอป KSMacExplorer
  4. (หากไม่พบแอปในรายการ ให้กดปุ่ม + ด้านล่าง แล้วเลือกแอป KSMacExplorer เข้าไป)
